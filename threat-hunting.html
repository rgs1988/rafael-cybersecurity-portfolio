THREAT HUNTING - EJECUCIÓN REMOTA

El laboratorio tiene como finalidad simular un escenario de ejecución remota de código, donde un host atacante (REDQUEEN, Kali Linux) accede a un recurso compartido en una máquina víctima con Windows 10 (usuario fguajardo), perteneciente al dominio YORHA, para ejecutar un script malicioso de PowerShell desde una ruta remota vía SMB.

Durante la simulación, el atacante emplea credenciales válidas para autenticarse en el sistema, accede al recurso compartido “nuevo” y ejecuta un script (.ps1) utilizando parámetros de evasión. Esto permite replicar técnicas reales como movimiento lateral y Living off the Land.

La actividad será analizada en Splunk correlacionando eventos de Windows y Sysmon.

Máquinas utilizadas:

Sistema Operativo Nombre Cuenta Dominio IP
Windows Server 2025 Administrador Administrador YORHA 192.168.1.89
Windows 10 fguajardo Usuario YORHA 192.168.1.88
Windows 10 REDQUEEN Atacante Sin dominio 192.168.1.97
