RADIUS SETUP - AUTENTICACIÓN CENTRALIZADA

Este trabajo presenta la implementación de un entorno de autenticación centralizada utilizando FreeRADIUS integrado con Active Directory.

A lo largo del laboratorio se configuró un servidor Linux capaz de comunicarse con el dominio, validar credenciales mediante winbind y utilizar ntlm_auth como puente hacia AD.

El objetivo fue construir un flujo realista de autenticación empresarial, comprendiendo tanto la integración técnica como las diferencias entre métodos como PAP y MSCHAP, así como las limitaciones de las herramientas de prueba utilizadas.

Máquinas utilizadas:

Sistema Operativo Nombre Cuenta Dominio IP
Ubuntu Linux RADIUS Server Administrador YORHA 192.168.1.86
Windows Server 2025 Controlador de Dominio Administrador YORHA 192.168.1.89
