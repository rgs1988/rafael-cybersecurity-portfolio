LOGIN ANALYSIS

El laboratorio tiene como finalidad simular un ataque de fuerza bruta, donde el equipo REDQUEEN (Kali Linux) intenta acceder a recursos compartidos mediante el uso de credenciales del usuario víctima fguajardo, en un entorno Windows 10 integrado al dominio YORHA.

La actividad generada será analizada en Splunk con el objetivo de identificar, correlacionar y estudiar los eventos de seguridad producidos durante el intento de intrusión.

Para este laboratorio se utilizaron las siguientes máquinas virtuales:

Sistema Operativo Nombre Cuenta Dominio IP
Windows Server 2022 Administrador Administrador AD YORHA 192.168.1.89
Windows 10 fguajardo Usuario YORHA 192.168.1.88
