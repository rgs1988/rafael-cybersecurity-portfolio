Threat Hunting: Detección de Procesos en SIEM

El laboratorio tiene como objetivo simular un escenario de ejecución remota de código, en el cual el host atacante REDQUEEN (Kali Linux) accede a un recurso compartido en la máquina víctima Windows 10 (usuario fguajardo), perteneciente al dominio YORHA, para ejecutar un script malicioso mediante PowerShell desde una ruta remota SMB.

Durante el ataque, el adversario utiliza credenciales válidas para autenticarse en el sistema, accede a la carpeta compartida “nuevo” y ejecuta un script (.ps1) empleando parámetros de evasión, simulando técnicas reales de movimiento lateral y uso de herramientas legítimas del sistema (Living off the Land).

La actividad generada es monitoreada y analizada a través de Splunk, integrando eventos de Windows Security Logs y Sysmon, con el objetivo de identificar, correlacionar y reconstruir la cadena completa del ataque, desde la autenticación inicial hasta la ejecución del código malicioso.
