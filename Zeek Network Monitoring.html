ZEEK NETWORK MONITORING

Esta guía documenta la implementación y uso de Zeek como plataforma de monitoreo y análisis de tráfico de red orientada a ciberseguridad.

El laboratorio fue desarrollado en un entorno Linux Ubuntu, donde se configuró Zeek como sensor de red para capturar telemetría en tiempo real y generar registros estructurados de protocolos como DNS, HTTP y conexiones TCP/UDP.

A lo largo de la guía se realizan ejercicios prácticos de análisis de tráfico, detección de anomalías y simulación de comportamientos sospechosos, incluyendo escaneo de puertos y DNS Beaconing, permitiendo comprender cómo Zeek puede utilizarse en entornos Blue Team y SOC para actividades de monitoreo, Threat Hunting y detección de amenazas.

Además, se integra Zeek con Splunk Enterprise mediante Splunk Universal Forwarder, centralizando la telemetría para correlación y análisis avanzado de eventos de seguridad. El objetivo principal es demostrar cómo construir un laboratorio funcional de Network Security Monitoring (NSM) capaz de generar visibilidad sobre el comportamiento de la red y apoyar procesos de detección e investigación.
